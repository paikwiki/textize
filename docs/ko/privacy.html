개인정보 처리방침

시행일 2026년 10월 17일

Textize는 어떤 데이터도 수집하지 않습니다. 이 문서는 앱이 소리와 글을 어떻게 다루고 맥에 무엇을 저장하는지 설명합니다.

Textize가 하지 않는 것

  • 자막으로 바꾸는 소리를 수집, 저장, 전송하지 않습니다.
  • 만든 자막과 번역문을 수집, 저장, 전송하지 않습니다.
  • 마이크를 쓰지 않습니다.
  • 분석 도구, 충돌 보고, 광고 식별자, 계정을 쓰지 않습니다.
  • 개발자가 운영하는 어떤 서버에도 접속하지 않습니다.

소리는 어떻게 처리되나요

Textize는 macOS의 시스템 오디오 녹음 권한으로 맥에서 재생 중인 소리를 받아 macOS 내장 음성 인식에 넘깁니다. 번역 언어를 고르면 인식한 문장을 macOS 내장 번역 기능으로 번역하므로 두 단계 모두 맥 안에서 끝납니다. 소리와 글은 화면에 보이는 동안만 메모리에 머물고, 자막을 지우거나 앱을 종료하면 사라집니다.

macOS가 처리하는 다운로드

음성 모델과 번역 언어 팩은 해당 언어를 처음 사용할 때 macOS가 Apple에서 다운로드합니다. 이 다운로드에는 Apple의 개인정보 처리방침이 적용됩니다. 다운로드한 뒤에는 인식과 번역이 인터넷 연결 없이 동작합니다.

맥에 저장되는 것

Textize는 환경설정을 맥의 macOS 표준 설정 저장소에 저장합니다. 선택한 음성·번역 언어, 글자 크기와 배경 투명도 같은 표시 옵션, 인터페이스 언어, 자막 창의 위치입니다. 자막 내용은 저장하지 않으며, macOS 통합 로그에 남기는 진단 메시지에도 개수나 언어 코드 같은 기술 정보만 들어갑니다.

변경

Textize가 데이터를 다루는 방식이 달라지면 이 문서를 갱신하고 앱의 릴리스 노트에 그 변경을 적습니다.
