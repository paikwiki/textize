모든 소리에 자막

음성 언어를 설정하면 맥에서 나는 모든 소리에서 해당 언어를 감지해 자막으로 보여줍니다.

전부 기기 안에서

음성 인식과 번역 모두 Apple 내장 프레임워크로 처리합니다. 데이터를 외부로 전송하지 않습니다.

실시간 번역

원문/원문+번역/번역 모드를 선택할 수 있으며, 특정 문장만 선택해 원문 또는 번역을 볼 수도 있습니다.

방해하지 않는 창

자막 창은 다른 창에 대한 클릭이나 스크롤 이벤트를 방해하지 않습니다. 일정시간 음성 입력이 없을 때 자동 창 숨기기를 지원합니다.

지나간 자막 다시 보기

우측 스크롤 영역에서 스크롤해서 지난 자막을 볼 수 있습니다.

6개 언어 인터페이스

English, 한국어, 日本語, Español, Français, Deutsch.

어떻게 동작하나요

Textize는 Core Audio의 프로세스 탭으로 맥에서 재생 중인 소리를 받아 macOS 내장 음성 인식에 넘기고, 인식한 글을 문장 단위로 끊어 자막 창에 띄웁니다. 외부로 데이터를 전송해서 처리하지 않고 맥의 내장 기능만을 사용하며, 시스템 오디오 녹음 권한만 요구합니다. 자막 번역은 macOS에 내장된 번역 기능을 사용합니다.

음성 모델과 번역 언어 팩은 해당 언어를 처음 사용할 때 다운로드하며, 인터넷 연결 없이 동작합니다. 음성 모델은 최대 5개 언어까지 저장할 수 있습니다.

요구 사항
